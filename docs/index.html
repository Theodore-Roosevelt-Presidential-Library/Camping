Staff notes

This page previews the public land camping guide. To place it on a trlibrary.com page, paste this into a code block:

<div id="trpl-camping"></div>
<script src="https://camping.labs.trlibrary.com/camping.js" defer></script>

Add data-heading="off" to the script tag when the page already has its own heading.

Just the "Am I on public land?" button

<div id="trpl-camping-check"></div>
<script src="https://camping.labs.trlibrary.com/camping.js" data-view="check" data-target="#trpl-camping-check" defer></script>

Compact conditions (sidebar or homepage)

<div id="trpl-camping-mini"></div>
<script src="https://camping.labs.trlibrary.com/camping.js" data-view="compact" data-target="#trpl-camping-mini" data-more="https://www.trlibrary.com/..." defer></script>

Full-screen map for phones

camping.labs.trlibrary.com/map/ opens the check button and map full screen. It can be added to a phone's home screen, and "Save this area for offline" keeps the map working with no signal.
